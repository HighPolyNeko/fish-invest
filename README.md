# Рынок редкой рыбы

Кликер-пародия на мем «Инвестиции в редкую рыбу / Множество дядей» — серию мемов о культуре мошенничества, где людям саркастически предлагают вложиться в «рынок редкой рыбы» и окружить себя «множеством дядей».

## 🎮 [Играть](https://highpolyneko.github.io/fish-invest/)

https://highpolyneko.github.io/fish-invest/

Это игра, а не инвестиционный совет. Все цифры внутри вымышлены и не отражают реальных цен или доходности.

## Запуск у себя

Сборка не нужна: открой `index.html` в браузере или подними любой статический сервер в папке проекта, например:

```
python -m http.server 8123
```
