# Рынок редкой рыбы

Кликер-пародия на мем «Инвестиции в редкую рыбу / Множество дядей» — серию мемов о культуре мошенничества, где людям саркастически предлагают вложиться в «рынок редкой рыбы» и окружить себя «множеством дядей» как ключом к финансовому успеху.

Это игра, а не инвестиционный совет.

## Запуск

Игра — один файл [`idle.html`](idle.html). Откройте его в браузере, сборка не нужна.

## Работа с репозиторием

Ветки, правила PR, мержа и релизов описаны в [CONTRIBUTING.md](CONTRIBUTING.md).
Коротко: `develop` — общий ствол, `feature/*` и `release/*` отрезаются от него, `main` только догоняет релизы, ушедшие на прод.
